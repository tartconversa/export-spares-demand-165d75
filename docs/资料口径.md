# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

stock_events 数量为库存变化：receipt及return为正，issue为负。工单opened_at为报修，failed_at为已核实故障起点；repair_at为空表示未恢复。parts_per_repair 指配套需要数量，两个 required_group 不同的物料须同时满足才可修复；同组替代件任选，替代受固件及资质限制。运输情景是使用者输入的假设，不能视作已观测概率真值。borrow 在承诺后从出借站可保障库存中扣除，但收件方在运输到达前不能算已到库存。返修验收合格才可回库。

## stations
海外合成站点，均使用北京时间资料时刻。

记录键：['station_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| station_id | string | 站 |
| region | string | 区域 |
| qualification | string | 资质 |
| service_hours | integer | 恢复时限小时 |

## parts
物料和订货。

记录键：['part_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| part_id | string | 物料 |
| unit_cost | number | 单价 |
| cash_days | integer | 付款账期 |
| normal_days | integer | 常规交期 |
| expedite_days | integer | 加急交期 |
| expedite_cost | number | 单件加急费 |

## installed_base
投运与保障设备。

记录键：['unit_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| unit_id | string | 设备 |
| station_id | string | 服务站 |
| generation | string | 代际 |
| firmware | string | 固件 |
| commissioned | date | 投运 |
| warranty_end | date | 保障结束 |
| environment | string | 环境 |

## work_orders
真实需求观察含未修复工单。

记录键：['order_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| order_id | string | 工单 |
| unit_id | string | 设备 |
| failed_at | datetime | 故障起点 |
| opened_at | datetime | 报修 |
| repair_at | datetime | 恢复或未知 |
| state | string | closed或waiting |
| consequence | integer | 服务后果权重 |
| available_at | datetime | 可知时点 |

## stock_events
本包起始库存零，事件构成全部现存库存。

记录键：['stock_event_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| stock_event_id | string | 事件 |
| station_id | string | 站 |
| part_id | string | 物料 |
| occurred_at | datetime | 时点 |
| kind | string | 变化原因 |
| quantity | integer | 有符号数量 |

## part_uses
领件到工单，一工单可重复领退。

记录键：['use_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| use_id | string | 记录 |
| order_id | string | 工单 |
| station_id | string | 站 |
| part_id | string | 物料 |
| quantity | integer | 数量 |
| occurred_at | datetime | 领退时点 |
| kind | string | issue或return_accepted |

## compatibility
相容配套，其中G2需主件与P4配套；high站可用P3替代。

记录键：['generation', 'firmware', 'required_group', 'part_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| generation | string | 代际 |
| firmware | string | 固件 |
| required_group | string | 配套组 |
| part_id | string | 物料 |
| parts_per_repair | integer | 数量 |
| min_qualification | string | 资质 |

## shipments
已下单在途物料，同批共享路线风险。

记录键：['shipment_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| shipment_id | string | 批次 |
| part_id | string | 物料 |
| station_id | string | 目的站 |
| quantity | integer | 数量 |
| earliest | date | 最早到日 |
| latest | date | 最迟到日 |
| route | string | 路线 |
| redirect_cost | number | 改港费 |

## stockouts
独立登记的缺货区间，库存事件保留原数量。

记录键：['station_id', 'part_id', 'start']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| station_id | string | 站 |
| part_id | string | 物料 |
| start | date | 开始 |
| end | date | 结束 |
| reason | string | 原因 |

## plans
从资料第110日起未来90日的情景新增设备，均匀投运、代际构成同本站当前在保设备只是可改的情景假设；预算为全网每情景总额，不是每站各一份。

记录键：['scenario_id', 'station_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| scenario_id | string | 假设 |
| station_id | string | 站 |
| new_units | integer | 新增设备 |
| route_delay_days | integer | 区域共同迟延 |
| failure_multiplier | number | 区域共同需求倍数 |
| budget | number | 本方案总预算 |
